# 🛡️ SafeSearch (echo-search)

[![License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)  
[![GitHub Stars](https://img.shields.io/github/stars/echo-search/safesearch?style=social)](https://github.com/echo-search/safesearch/stargazers)  
[![GitHub Issues](https://img.shields.io/github/issues/echo-search/safesearch?style=social)](https://github.com/echo-search/safesearch/issues)  
[![GitHub Forks](https://img.shields.io/github/forks/echo-search/safesearch?style=social)](https://github.com/echo-search/safesearch/network)  

SafeSearch is a **kid-friendly, primary-school-focused search engine** built on the principles of **EchoSearch**, but limited to **trusted educational websites**. Perfect for classrooms, homeschooling, and the Girl Gang’s safe learning adventures.  

---

## 🌟 Features

<details>
<summary>Click to expand SafeSearch Features</summary>

- ✅ **Safe & filtered:** Only searches approved educational sites.  
- 🔎 **Fast search:** Optimized search index for primary content.  
- 📚 **Covers all subjects:** Reading, Maths, Science, Coding, Creativity, Arts, Wellbeing.  
- 🌐 **Supports subdomains:** Finds resources across all trusted platforms.  
- 🖥️ **Customizable:** Add/remove sites easily via CSE list.  
- 🎨 **Kid-friendly interface:** Clean, colorful, simple navigation.  
- ⚡ **No distractions:** No ads, popups, or unrelated content.  
- 📈 **Optional analytics:** See which sites are used most.  

</details>

## 🚀 Getting Started

1. **Clone the repository**  
git clone https://github.com/echo-search/safesearch.git  
cd safesearch

2. **Open `index.html`** in a browser or host it on GitHub Pages.  

3. **Search safely** — all queries are restricted to the trusted educational sites.

---

## 💡 Why SafeSearch?

SafeSearch makes learning **stress-free and distraction-free**, perfect for teachers, parents, and young students. The Girl Gang can explore safely without accidentally landing on unverified content!
